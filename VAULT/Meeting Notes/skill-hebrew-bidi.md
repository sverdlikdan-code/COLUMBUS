# Skill: hebrew-bidi

## Статус
✅ Активен | Создан: 2026-07-05 | PRD: 2026-07-28

## Что делает
Справочник для работы с ивритским текстом в COLUMBUS. Отвечает на вопрос "какую BiDi-функцию вызвать" для каждого источника данных.

## Триггер
Любой ивритский текст выглядит перевёрнутым, цифры в неправильном порядке, или новая HTML-страница требует RTL layout.

## Карта функций
| Источник | Функция |
|----------|---------|
| Power BI DAX/REST | fixBiDi() |
| Legacy SQL (планограмма) | fixVisualRTL() |
| Семейства планограммы | fixHebRTL() |
| Адреса клиентов PBI | fixBiDiAddress() |
| HTML браузер | _ltrWrap() + dir= |

## Известные риски
- fixBiDi продублирована в 4 файлах — синхронизировать при изменении
- export-gps-report.js использует упрощённую версию без fix цифр
