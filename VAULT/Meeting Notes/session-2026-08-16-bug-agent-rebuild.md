## Что произошло

### Симптом
הזמנת דגים (MAHSAN) показывал banner "⚠ שגיאת שרת — מכר ממוצע קבוע".
Данные планограммы в норме, только period-based sales не грузились.

### Диагностика (post-mortem)
- error.log последний раз записан **14 августа** → сервер не крашился сегодня
- Причина баннера сегодня: не установлена точно (нет timestamps в PM2 логах)
- Баннер исчез после рестарта сервера

### Реальные баги найдены в error.log (14 августа)
1. `addWorksheet('')` в `/api/export-all-days-xlsx` — когда у клиента нет дня → throw в async handler без try/catch → unhandled rejection → pm2 перезапускает сервер
2. BOM JSON parse error — отдельная проблема, не главная причина

### Фиксы применены
- `addWorksheet`: фильтрация пустых дней + try/catch вокруг всего handler'а
- Server-side cache 60 мин для `/pbi/dagim-sales` — PBI временно недоступен → отдаём стейл вместо 500
- PM2 `--time` включён → теперь все строки лога с timestamp
