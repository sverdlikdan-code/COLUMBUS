# Session 2026-05-25 — Formula Road: RTL Fix, Azure Maps, Jitter, pct Fix

**Статус:** ✅ done

## Что было сделано

### 1. RTL Hebrew names fix (Priority ERP)
- Priority ERP экспортирует иврит в визуальном LTR-порядке с Unicode-маркерами U+202D/U+202C
- `fixPriorityAddr()` в `build-formula-road.js`: если строка содержит dirmarks → стрипаем, разворачиваем, корректируем цифры
- Применяется к `custName`, `city`, `address` в `mapClient()`
- Итог: имена и адреса клиентов корректны в popup и списке

### 2. Azure Maps geocoding fallback
- Cascade: PBI coords (bbox) → Nominatim → Azure Maps (адрес) → Azure (город) → city-center
- Persistent cache: `docs/azure-geocode-cache.json` — key=query, value={lat,lng} или null
- Azure-ответ содержит `boundingBox` → сохраняем в `cityBBoxCache` для bbox-валидации неизвестных городов
- Результат: no-GPS = 0 для большинства маршрутов (было 155, было 45, теперь ~0)

### 3. City-center markers
- `gpsSource === 'city-center'` → серый маркер `~N` с 80% opacity
- Jitter `±15м` на основе `custId` чтобы markers одного города не стекались
- Popup предупреждение: "⚠ מיקום משוער — מרכז עיר"

### 4. Duplicate GPS jitter
- Два клиента с одинаковыми координатами (напр. #4 и #20) сливались в "20-4"
- Фикс: `_coordCount` + `_coordIdx` перед `list.forEach` — spread по offset index

### 5. pct (ביצוע) fix — 514% bug
- `c.pct === 0` falsy → fallback на `totalSales/target` давал 514%
- Исправлено: `const pct=c.target?Math.round((c.monthlySales||0)/c.target*100):0;`
- `totalSales` удалён из DAX и `mapClient()` полностью

### 6. Excel save button
- Зелёная кнопка `#1D6F42` в стиле Excel, иконка "XL", текст "שמור"
- Перенесена в группу sort-btns

### 7. City detection fix
- `detectCity()`: расширен список fallback полей Nominatim (suburb, neighbourhood, municipality, county, state_district)
- `display_name.split(',')[0]` — если всё пусто, не показывать координаты
- `confirmCity()`: GPS coords не обнуляются если уже установлены

### 8. Delivery docs
- `generate-delivery-docs.js` — 2 проекта в одном Excel, 6 листов
- FR (синий) + MAHSAN (зелёный): бעיות ופתרונות, מה נמסר, שעות
- 5 проблем + решения для каждого, таблица часов по дням
