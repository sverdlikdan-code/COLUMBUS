## MMD ORDERS → GitHub Pages (без зависимости от PC) ✅

**Проблема:** Cloudflare Error 1033 при выключенном PC — приложение было привязано к локальному серверу.

**Решение:** Статический деплой по паттерну MAHSAN/Formula Road.

### Что создано
- `server/build-mmd-orders.js` — standalone build script: DAX → `docs/mmd-orders.json` (424 продукта)
- `.github/workflows/mmd-orders-build.yml` — CI workflow, Workflow ID: 297430969
- `docs/mmd-orders.html` — статичная копия приложения (fetch `./mmd-orders.json`)
- `docs/mmd-orders.json` — pre-built данные, май-июнь 2026

**URL:** `https://sverdlikdan-code.github.io/COLUMBUS/mmd-orders.html`

### Расписание CI (IST)
07:00 / 13:00 / 14:10 / 15:00 / 16:00 / 18:00 / 19:00

### Архитектура
- Две версии: локальная (`/mmd` с живыми данными из PBI) и GitHub Pages (JSON, обновляется по расписанию)
- Все пользователи GitHub Pages видят один и тот же JSON
- F5 / רענון в браузере = перечитать тот же JSON (не вызов PBI)
- После PBI רענון — данные появятся в приложении на следующем CI-слоте (макс 2ч)
