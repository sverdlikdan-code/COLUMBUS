### fixProductName — нормализация ג
- Проблема: `ג'004`, `ג ' 25`, `ג'032` не парсились
- Причина: Hebrew + smart quotes в regex literals → `SyntaxError` в Node.js v24 внутри HTML `<script>`
- Решение: `new RegExp('...\uXXXX...')` — два паттерна, один для `ג[apo]digits`, один для `[apo]ג digits`
- Ключевое открытие: Hebrew в regex литералах внутри HTML файлов → парсинг ломается в Node.js v24. Всегда использовать `new RegExp()` с unicode escapes
