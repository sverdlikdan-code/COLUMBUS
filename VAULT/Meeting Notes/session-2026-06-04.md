# Сессия 2026-06-04 — Formula Road: BiDi geocoding fix

## Задачи (продолжение с 2026-06-03)

### ✅ Исправлены satellite labels (vertical strip bug)
- **Причина:** `position:absolute;left:44px` внутри контейнера `width:38px` → available width = -6px → `word-break:break-word` сжимает текст до 1 символа в строку
- **Fix:** `width:max-content` — обходит containing block, использует intrinsic content width

### ✅ Диагностика 4 NO GPS клиентов (1127014, 1126078, 1111106, 1151213)
- Причина: Power BI (Priority ERP) отдаёт адреса в BiDi visual order (LRO ‭ + reversed Hebrew chars)
- `‭51 יקצדורוג‬` → после strip BiDi → `51 יקצדורוג` → геокодер находит в Petah Tikva (wrong city)
- Правильный адрес: `גורודצקי 51, רחובות`
- Excel gps-report тоже затронут: 53 из 503 записей — неправильный город

### ✅ Fix export-gps-report.js — BiDi reversal
- Добавлена `fixBiDiHebrew(raw)`:
  - Определяет наличие BiDi control chars (BIDI_TEST, no `g` flag)
  - Стрипает их (BIDI_STRIP, `g` flag)
  - Разворачивает: каждое Hebrew-слово reverse chars + reverse word order; числа оставляет в конце
- Применена ко всем полям: custName, city, address, agentName
- Тест: `‭51 יקצדורוג‬` → `גורודצקי 51` ✓; `‭46 םותי השמ‬` → `משה יתום 46` ✓
- Старые неправильные cache-записи не удаляются — просто не используются (новые logical-order ключи)
