## Мультикомпьютерный workflow — как держать синхронизацию
- Watchdog (`COLUMBUS-Daily-06`, `COLUMBUS-Watchdog-0730` в Windows Task Scheduler) существует **только на этом компьютере** — это локальные задачи планировщика, не передаются через git, на втором компе не появятся
- `setup-new-computer.ps1` НЕ регистрирует scheduled tasks — второй комп работает только вручную
- Рекомендованная схема: на втором компе — `git pull` перед началом работы, `git add`/commit/`git push` после; пушить чаще (особенно до 06:00/07:30, когда срабатывает watchdog здесь), чтобы не плодить конфликты вроде только что разрешённого
