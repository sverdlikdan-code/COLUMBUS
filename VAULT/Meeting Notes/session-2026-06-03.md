## После лимита — диагностика autoCompact (вечер)

### Почему autoCompactEnabled не сработал

**Вывод 1:** Настройки были добавлены **во время** той самой сессии — не могли предотвратить уже случившееся.  
**Вывод 2:** `autoCompactWindow: 150000` — **несуществующая настройка**. Claude Code не знает этого параметра. Просто мёртвый JSON.  
**Исправлено:** `autoCompactWindow` удалён из `.claude/settings.json`.

**Как autoCompact реально работает:**
- Срабатывает когда контекст ~200K токенов (конец стандартного окна)
- Делает сжатие предыдущих сообщений
- Если не хватило — Claude переходит на 1M контекст (нужны credits)

**Главная защита:** новая сессия после каждого крупного блока mahsan-работы. При 40+ итерациях build→fix за день autoCompact не спасает.
