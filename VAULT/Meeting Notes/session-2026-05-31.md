### Mahsan — build-kapua-new.js: чистка garbled fam

Добавлена автоматическая чистка мусорных значений `fam` в рабочих слотах при каждом билде:
```javascript
const knownFams = new Set(FAM_ORDER_LIST);
for (const [pk, p] of Object.entries(picks)) {
  if (p && p.fam && !knownFams.has(p.fam)) picks[pk] = { ...p, fam: null };
}
```
Причина: старые билды на MLAY/Excel оставляли в picks garbled-значения (типа `'דומ` вместо `מוסדי`). KARTIS PARIT один вариант написания семейства — не два.
