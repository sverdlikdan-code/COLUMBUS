### 2. Редактируемый KARTON — live update
Колонка KARTON стала `<input type="number" class="ord-k-input">` с `data-krat` и `data-mk`.

При изменении KARTON:
- `_recalcRowPal(this)` → пересчитывает PALLET = karton / krat
- Обновляет `.ord-p-auto[data-mk]` и `.ord-pal-input[data-mk]`
- Синхронизирует `_orderCurrentRows[i].orderK / .orderP` → Excel-экспорт отражает ручные правки
- `_recalcOrdTotal()` → обновляет header KPI: `ord-k-hdr`, `ord-pal-hdr`, `ord-pal-gt-cell`, `ord-cont-hdr`

### 3. PAL ידני → обратная связь с KARTON
При изменении PALLET-input (`ord-pal-input`):
- `_recalcRowK(this)` → KARTON = round(pallet × krat)
- Обновляет `ord-k-input` для той же строки
- Синхронизирует data array, вызывает `_recalcOrdTotal()`
- **step = 0.5** для сборных палет (можно выставить 1.5, 2.5 и т.д.)

### 5. Мультивыбор семейств (family chips)
- `window._orderFam` (строка) → `window._orderFams` (Set)
- Нажатие chip → toggle в Set; כולם → `Set.clear()`
- Фильтр: `_orderFams.size > 0 ? allRows.filter(r => _orderFams.has(getGrp(r))) : allRows`
- Несколько семейств выбраны одновременно — все подсвечиваются синим

### 6. Hover эффект на строки таблицы

Продуктовые строки получили class `ord-row`. Работает на любом цвете строки.

## Архитектура двусторонней синхронизации KARTON↔PAL
```
ord-k-input.oninput → _recalcRowPal(this)
  → обновляет ord-p-auto, ord-pal-input
  → синхронизирует _orderCurrentRows
  → _recalcOrdTotal() → header KPIs

ord-pal-input.oninput → _recalcRowK(this)
  → обновляет ord-k-input
  → синхронизирует _orderCurrentRows
  → _recalcOrdTotal() → header KPIs
```
