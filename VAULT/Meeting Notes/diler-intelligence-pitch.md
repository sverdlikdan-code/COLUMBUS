# Diler Intelligence — питч о выделении в отдельную структуру

## Суть
Дан (аналитик в Diler B.M.D. International) предлагает одному из собственников группы (Дмитрий Вайнберг) совместно учредить отдельную IT/AI/BI-компанию. Со стороны собственника — инфраструктура + 5 дистрибуционных + 3 импортёрских компании как первые клиенты. Со стороны Дана — 3 готовых продукта (Formula Road, Mahsan Editor, MMD Orders) как доказательство.

## Название
Прошло эволюцию: **DILL IT** (каламбур на Diler, но конфликт — уже есть компания "Dill", restaurant management SaaS, San Francisco) → **DILL AI** (обсуждался) → **Diler Intelligence** (финальный выбор, 2026-07-27) — "Intelligence" честно покрывает и BI (доказано: 16 SQL-запросов, 26 юзеров PBI) и AI (в основном roadmap, не доказанный факт).

## Файл
`BIZNES-AI/DILL IT/Diler Intelligence.html` — папка НЕ переименована (по просьбе пользователя), файл внутри называется по новому имени. Самодостаточный HTML (screenshots как base64), готов к отправке по почте — приватные Artifact-ссылки не гарантированно открываются на чужом устройстве.

## Структура питча (финальная логика, после ревизии)
Путь (Excel→SQL 16 запросов→26 юзеров) → этап ИИ-интеграции → почему скорость критична (FMCG-специфика, 3 ИИ-агента) → доказательства (3 продукта + הזמנת דגים/INTER на тесте + הזמנת מקרר в проде) → תוקף/סכнה крупным планом (238 SKU, per-партийный контроль сроков) → отдельное направление (роль аналитика → AI product management, DILL названо один раз, дальше Diler Intelligence) → преимущества структуры (уникальная экспертиза, ASCOMI как первый кандидат на замену, ~₪80k/год) → рыночная оценка (таблица ₪) → стек/выделенный сервер → roadmap (KPI-алерты, ИИ-аналитик с live-запросами, склад Север по образцу MMD Orders, голосовой бот, ASCOMI-логистика, аудит платных сервисов, ИИ-контроль фото мерчендайзеров, ИИ-анализ StoreNext, независимый аудит) → встреча.

**Важно:** личное обращение к Дмитрию убрано везде — документ нейтральный, не "письмо лично ему".

## Честная граница AI vs BI (принципиально для этого питча)
Mahsan Editor и MMD Orders — это BI + бизнес-правила (kratnost, תוקף-арифметика, SKU-overrides), НЕ ИИ во время работы приложения. Сам процесс разработки идёт через ИИ-агентов (Claude Code) — это ИИ честно. Настоящий "ИИ в продукте" — только в roadmap (voice bot, computer vision для фото, LLM-анализ StoreNext, NL→SQL аналитик). Пользователь подтвердил ценность этого разграничения — не переобещать на встрече то, чего нет технически.

## Priority ISV — отдельное открытое направление
Исследовано: Priority ISV/Technology Partner трек (не VAR) подходит стратегически — доступ к Priority Market (75k+ компаний, 70 стран). Технический нюанс: официальные интеграции идут через Open API/REST, не через прямой SQL (который используется для внутренней работы с Diler). Для внешнего ISV-продукта нужен отдельный слой на Open API — не расширение текущей SQL-миграции. Не начато технически, только подана бы заявка через форму.

**Не путать:** "שותפת Priority מורשית" в `BIZNES-AI/portfolio/pitch-he.html` — это **Yissumit HD**, отдельная от Diler компания Дана. Statement корректен для неё, не имеет отношения к Diler Intelligence.
