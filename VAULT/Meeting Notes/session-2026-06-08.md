### 2. Редактируемый KARTON (главная фича)
**Было:** колонка "הזמנה KARTON" — статический `<td>`, только отображение.  
**Стало:** `<input type="number" class="ord-k-input">` с `data-krat` и `data-mk`.

При изменении числа:
- `_recalcRowPal(this)` → пересчитывает PALLET для строки (= karton / krat)
- Обновляет `.ord-p-auto[data-mk]` — display-ячейку PALLET
- Обновляет `.ord-pal-input[data-mk]` — ручной PAL input
- Синхронизирует `window._orderCurrentRows[i].orderK` и `.orderP` → **Excel-экспорт отражает ручные правки**
- Вызывает `_recalcOrdTotal()` → обновляет header KPI: KARTON, PALLET, קונטיינר 40'

**Новые функции:**
- `_recalcOrdTotal()` — суммирует все `.ord-k-input`, вычисляет pallet через `data-krat`; обновляет `ord-k-hdr`, `ord-pal-hdr`, `ord-pal-gt-cell`, `ord-cont-hdr`
- `_recalcRowPal(inp)` — row-level recalc + sync to data array
- `_recalcOrdPal()` — теперь просто вызывает `_recalcOrdTotal()` (backward compat)

**Стиль input:**
- Оранжевый (`#fff8e1` bg, `#e65100` border, `#bf360c` text) если orderK > 0
- Зелёный (`#f1f8e9` bg, `#c8e6c9` border) если orderK = 0

### 3. Print fix — чёрный фон вокруг таблиц

**Фикс:**
```css
body.printing-order #order-table-wrap { background: #fff !important; padding: 0 !important; }

body.printing-order .ord-pal-input { border: none !important; background: transparent !important; }
```
