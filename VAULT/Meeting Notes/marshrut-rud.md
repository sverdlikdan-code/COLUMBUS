## Что сделано

### Матчинг клиентов
- Скрипт `server/match-marshrut-rud.js` — fuzzy matching из MARSHRUT RUD.xlsx по базе ASHDOD-RISHON.xlsx
- День 1: pool אשדוד; День 2: pool ראשון + בת ים (без חנויות)
- Output: `MARSHRUT-RUD-MATCHED.xlsx` с цветовой индикацией качества совпадения

### Генерация карты
- `server/regen-maps.js` — быстрая генерация из хардкоженных координат
- Оптимизация маршрута: nearest-neighbor + 2-opt (убирает пересечения) по всем стартовым точкам
- Клиент 1140011 (טיב טעם) — координаты исправлены на סטאר סנטר, הרצל, אשדוד (31.8101, 34.6557)

### Финальный HTML: `marshrut-rud.html`
- Две вкладки: יום 1 — אשדוד (16 клиентов) / יום 2 — ראשון לציון (16 клиентов)
- На карте: кружки с номерами (без лейблов, чисто)
- Клик на кружок → попап с полным названием + адрес + ID
- Сайдбар справа: полный список с адресами
- Кнопки вращения карты (←/↑/→) через leaflet-rotate плагин, шаг 15°
- Печать: A4 landscape, карта + список на одном листе
