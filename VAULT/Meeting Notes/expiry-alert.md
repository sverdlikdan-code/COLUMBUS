Ежедневный алярм из редактора махсана: карточки סכנה + STOP SALE из «דוח תוקף» письмом, вид как в аппе + PDF для печати.

- «Кнопка печати на видном месте» — в письме JS не работает, window.print() невозможен → PDF во вложении (своя простая вёрстка 2×2 на A4 из тех же картинок) + плашка «🖨 להדפסה» вверху письма
- Шлётся только если есть ≥1 карточка; Вс–Чт 07:30 Israel (04:30 UTC, после planogram-build 03:21 UTC); личное письмо каждому (RECIPIENT_NAMES)
