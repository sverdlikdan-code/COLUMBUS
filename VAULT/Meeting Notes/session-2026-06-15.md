## Что сделано

### 1. `#filter-row` wrapper — fix JS-удаления stock filters
`buildChips()` делал `while (bar.children.length > 2) bar.removeChild(bar.lastChild)` — удалял `#sk-inline` как 3-й child `#fbar` при каждой загрузке данных.

Решение: `#filter-row` wrapper (flex row) содержит три блока:
- `#fbar` (flex:1, transparent) — только dropdown семейств + chips компаний
- `<img id="fbar-logo">` — логотип по центру, opacity 13%
- `#sk-inline` — stock-фильтры СНАРУЖИ `#fbar`, JS не трогает

### 3. PBI refresh date badge
- `server/powerbi.js`: новая функция `getDatasetRefreshTime(datasetId)` — GET `/refreshes?$top=1` из PBI REST API
- `server/index.js`: в `/pbi/mmd-orders` handler — `refreshedAt = await getDatasetRefreshTime(MMD_DS)` → добавляется в `res.json()`
- `index.html load()`: парсим `j.refreshedAt`, форматируем как `⬆ עדכון PBI: дд/мм/гг чч:мм`

### 4. Checkbox inversion для семейств
**До:** `fams` = set исключений, checkboxes были BACKWARDS (checked = исключить).
**После:** checked = видно, uncheck = исключить. Теперь при `כולם` всё показывается = все чекнуты.

Изменения:
- `syncFamPanel()`: `cb.checked = !fams.has(cb.value)` + кнопка: `'N מוסתרות ▾'`
- `togFamChk(cb)`: `if (!cb.checked) fams.add(cb.value); else fams.delete(cb.value);`

### Планограмма — `מכר ממוצע` 97 при пустом периоде
Товар "פרובינציאל מצוג ודזיתים" (500x NP 6) не был в инвентаре до декабря 2025.
При выборе июнь-июль 2025: PBI не возвращает строку для этого מקט.
`_ps[mk]` = undefined → `?? d.daySalesAll` = 97 (текущий June 2026 average).

**Фикс** (`fa939db`): `_ps ? (_ps[mk] ?? d.daySalesAll ?? 0)` → `_ps ? (_ps[mk] ?? 0)`
Когда период активен и продаж нет → 0 (прочерк). `daySalesAll` только если период не выбран.
