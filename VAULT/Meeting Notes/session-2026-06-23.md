# Сессия 2026-06-23

## Что сделано

### Диагноз "אין חיבור לשרת" (демо-режим в приложении)

**Корневая причина**: Два cloudflared одновременно на старом и новом компе → туннель имел 8 соединений вместо 4 → Cloudflare рандомно слал запросы на старый комп → 503.

**Доп. баг**: `formula-road-data.json` не содержит ключ `agents` (был намеренно убран для безопасности в build-formula-road.js). `loadAgentList()` в server/index.js читал `.agents || {}` → пустой объект → агенты не могли войти.

### Фиксы

1. **Cloudflared cleanup**: `cloudflared tunnel cleanup 579497d4-...` — убрал старые коннекты с первого компа
2. **Пользователь остановил cloudflared на старом компе**
3. **Создан `~/.cloudflared/config.yml`** с ingress rule `service: http://localhost:3000` — без него cloudflared возвращал 503 для всех запросов (нет ingress rules)
4. **Фикс `loadAgentList()`** в server/index.js — теперь читает из `agentsByManager` если `agents` не найден

### Технические детали

- Сервер: Node.js PID 11280, порт 3000
- Cloudflared: 4 соединения (2xtlv02, 1xlhr, 1xmrs) — только этот комп
- Power BI: работает (токен AZURE через MSAL, executeDax ~6-7с)
- Git: HEAD был повреждён (объект 5ca97f4d не существовал локально) → `git reset --hard origin/master`
