# Цены на Power BI консалтинг — рынок Израиля 2025–2026

> Источники: PayScale IL, SalaryExpert, Glassdoor IL, Fulton Analytics, vidi-corp.com, scaleupally.io, TechBehemoths Israel, bibd.co.il

---

## Резюме

Открытых прейскурантов от израильских BI-компаний практически нет — все работают под запрос. Стоимость консалтинга привязана к международным ставкам, скорректированным под локальный рынок. Зарплатные данные сотрудников (PayScale, Glassdoor, SalaryExpert) дают косвенный ориентир для фрилансерских ставок. Единственная нашедшаяся в открытом доступе конкретная цена ретейнера — американская компания Fulton Analytics ($1,950/мес), используется как западный бенчмарк.

## Ключевые моменты

### 1. Почасовые ставки — Израиль (оценка)

Прямых публичных данных по израильским фрилансерам нет. Но на основе зарплатных данных можно вывести:

| Категория | ILS/час | USD/час (курс ~3.65) |
|---|---|---|
| Наёмный BI-разработчик (средний) | ₪109–₪112 | ~$30 |
| Junior BI (1–3 года, расчётный) | ~₪80–₪90 | ~$22–$25 |
| Senior BI (8+ лет, расчётный) | ~₪135–₪160 | ~$37–$44 |
| Фрилансер (рыночная наценка +30–50%) | ~₪150–₪200 | ~$41–$55 |
| Международная агентская ставка | — | $100–$250 |

Важно: ставки на Upwork от израильских фрилансеров для международных клиентов — $25–$90/час. Для локального израильского заказчика — ближе к ₪150–₪250/час у опытного фрилансера.

### 2. Стоимость проекта — внедрение дашборда

| Тип проекта | USD | ILS (ориентир) |
|---|---|---|
| Простой дашборд (1 источник, 1–2 недели) | $1,500–$5,000 | ₪5,500–₪18,000 |
| Средний дашборд (несколько источников, 3–6 недель) | $5,000–$20,000 | ₪18,000–₪73,000 |
| Полное BI-внедрение (ETL + несколько отчётов) | $15,000–$50,000+ | ₪55,000–₪185,000+ |
| Малый бизнес (стандартный пакет) | $3,000–$8,000 | ₪11,000–₪29,000 |

Типичный первый проект для SMB в Израиле: **₪15,000–₪40,000** (оценка).

### Глобальные бенчмарки (для сравнения)

- США/UK/Австралия: $100–$250/час для консультанта
- Upwork global average: ~$87/час
- Восточная Европа/Индия: $20–$50/час
- Израиль по уровню рынка — ближе к Западной Европе (~$40–$80/час для фрилансера)

### Типичная структура проекта внедрения

1. Discovery & scoping: 5–10 часов
2. Data modeling + ETL: 20–60 часов
3. Dashboard development: 20–80 часов
4. Testing + training: 5–15 часов
5. Итого: 50–165 часов для среднего проекта

При ставке ₪150–₪200/час = **₪7,500–₪33,000** (реалистичный диапазон для израильского фрилансера, малый/средний бизнес).
