# Yael Agent — PRD

**Version:** 1.0
**Date:** 2026-06-18
**Status:** Draft

---

## Description

`Yael` — копирайтер-агент COLUMBUS. Переписывает черновые статьи из `Content/` в голосе и стиле бренда проекта (RU/EN/HE), интегрирует изображения от `Yuval`, когда они нужны. Только LLM — не использует внешние инструменты, кроме вызова Yuval.

Отвечает CEO. Не управляет другими агентами — только вызывает Yuval напрямую за изображениями.

---

## Problem It Solves

Черновики (заметки, тезисы, сырой текст из питчей/отчётов) не готовы к публикации — нет единого тона, нет структуры под тип контента (маркетинг/блог/B2B/слайды), нет переводов между RU/EN/HE. Без агента это делается вручную каждый раз с разным результатом.

`Yael` гарантирует постоянный Brand Voice и формат вывода независимо от того, кто и когда запускает переписывание.

---

## Goals

1. **Консистентный голос бренда** — один и тот же тон во всех материалах (B2B / слайды / маркетинг / блог)
2. **Многоязычность** — RU ↔ EN перевод с сохранением тона; HE для слайдов и презентаций
3. **Интеграция изображений** — вызывает Yuval точечно, не более 3 изображений на статью
4. **Предсказуемый вывод** — всегда `Output/<filename>.md` + перемещение черновика в `Content/Ready/`
5. **Без искажения фактов** — переписывает стиль, не придумывает данные

---

## Scope

### In Scope

- Переписывание/редактирование/резюмирование/перевод текста (только LLM)
- Определение типа контента и применение профиля (маркетинг / блог / B2B / слайды / креатив)
- Вызов Yuval за изображениями по `[IMAGE: <описание>]` меткам (макс. 3 на статью)
- Сохранение результата в `Output/`, перемещение черновика в `Content/Ready/`
- Brand Voice для B2B-дистрибуции (годовые отчёты, питчи, слайды)

### Out of Scope (v1)

- Веб-поиск (нет доступа к интернету/поисковым системам)
- Прямая генерация изображений (только через Yuval)
- Любые API-вызовы кроме внутреннего вызова Yuval
- Финальная проверка качества (это зона `Guy`, если активирован)

---

## Inputs / Outputs

### Inputs

- Черновые файлы `.md` / `.txt` в `Content/` (не в `Content/Ready/`)
- Инструкция пользователя (тип контента, язык, длина)
- Brand Voice профиль (зашит в `AGENT.md`)
- Изображения от Yuval (путь в `outputs/`)

### Outputs

- `Output/<filename>.md` — готовая статья с фронт-маттером (title, date, language, type, original)
- Перемещённый черновик в `Content/Ready/<filename>`
- Отчёт пользователю: "Яэль закончила — `Output/<filename>.md` готов"

---

## Architecture

```text
Trigger (CEO / пользователь)
        │
        ▼
      Yael
  ├─ Сканировать Content/
  ├─ Прочитать черновик полностью
  ├─ Определить язык + тип контента
  ├─ Отметить [IMAGE: ...] места
  ├─ Вызвать Yuval (если нужны изображения)
  ├─ Переписать согласно Brand Voice + профилю типа
  ├─ Сохранить в Output/
  └─ Переместить черновик в Content/Ready/
```

## Content Type Profiles

| Профиль | Когда применять | Ключевая черта |
|---------|------------------|----------------|
| Маркетинговый | Реклама, лендинги | Сильный hook + CTA |
| Блог | Образовательный контент | SEO-заголовок + подзаголовки каждые 200–300 слов |
| B2B | Питчи, отчёты для бизнеса | Проблема → решение → результат, без сленга |
| Слайды | Годовые отчёты, презентации | ≤7 слов заголовок, факт+динамика, цифры всегда |
| Креативный | Storytelling | Сцена → герой/конфликт → эмоциональная концовка |

## Image Decision Rules

**Вызывать Yuval:**
- Конкретный продукт/место/визуальное событие упомянуто
- Раздел про процесс/шаги (инфографика)
- Hero-изображение для открытия статьи
- Явная инструкция пользователя

**Не вызывать:**
- Изображение уже встроено в черновик
- Уже 3 изображения в статье
- "Для красоты" без содержательного вклада

---

## Quality / Acceptance Criteria

- [ ] Перед переписыванием черновик прочитан полностью
- [ ] Brand Voice профиль применён согласно типу контента
- [ ] Не более 3 вызовов Yuval на статью
- [ ] Факты не изменены — только стиль и формулировки
- [ ] Результат сохранён в `Output/`, черновик перемещён в `Content/Ready/`
- [ ] Отчёт о готовности выдан только после фактического сохранения файла

---

## Error Handling

- `Content/` пуста → "В Content/ нет статей — добавь черновой файл для начала"
- Yuval не вернул путь к изображению → пропустить изображение, продолжить без него, отметить в выводе
- Неясный тип контента → уточнить у пользователя перед переписыванием

---

## Security

- Не использует внешние API кроме внутреннего вызова Yuval
- Нет доступа к интернету — не может получить/передать данные вовне
- Работает только с локальными файлами `Content/` и `Output/`
