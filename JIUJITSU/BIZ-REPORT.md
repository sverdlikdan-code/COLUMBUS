## 1. Executive Summary

JJS Moveset Generator — веб-инструмент для генерации кастомных moveset кодов в игре Jujutsu Shenanigans (Roblox). Продукт уже работает локально (Node.js + Express), генерирует валидные коды и имеет decode функцию. Рынок реален: 6.14 млрд визитов, 145–200K concurrent daily, два конкурента — оба без рабочего генератора. Монетизация возможна через freemium ($3–5/мес) или разовый unlock ($4.99). Легальных рисков нет при соблюдении базовых правил. Критическое окно — 3–6 месяцев.

## 9. Легальные риски

### Риск 1: Нарушение Roblox ToS — НИЗКИЙ (5%)
**Суть:** Roblox может заявить что инструмент нарушает их Terms of Service.
**Реальность:** ToS Roblox запрещает только: торговлю Robux/аккаунтами, модификацию клиента, сбор лишних данных через API. Наш инструмент — офлайн-генератор, не трогает Roblox API вообще.
**Прецеденты:** RoWifi, Bloxlink, Rolimons, RTrack существуют годами без претензий. Единственный иск (PlayerAuctions, 2025) — за торговлю Robux.
**Защита:** Не называться "официальным Roblox", не торговать Robux, добавить disclaimer.

### Риск 2: Изменение формата кодов разработчиком JJS — СРЕДНИЙ (25%)
**Суть:** Разработчик JJS обновит формат base64/zstd кодов, наш генератор перестанет работать.
**Реальность:** Это технический риск. Игры обновляются, форматы меняются.
**Защита:** Мониторинг патчноутов JJS, абстрагированный encoder (легко менять), decode функция поможет быстро реверс-инжинирить новый формат.
**Время на фикс:** 1–3 дня при активном мониторинге.

### Риск 3: Trademark / Branding — НИЗКИЙ (10%)
**Суть:** Roblox Corp может потребовать убрать слова "Roblox", "JJS" из названия инструмента.
**Реальность:** Использование названий игр в описательных целях (fan tool) защищено nominative fair use.
**Защита:** Не называть продукт "Official JJS Tool" или "Roblox Generator". Использовать: "JJS Moveset Generator" или "Custom Skill Code Builder for JJS".

### Риск 4: GDPR / Privacy — СРЕДНИЙ (20%) если добавить аккаунты
**Суть:** При сборе email/данных пользователей нужно соблюдать GDPR (если есть пользователи из EU).
**Защита:** Cookie banner, Privacy Policy, хранение только необходимого минимума. Clerk (auth) и Stripe (payments) уже GDPR-compliant.
