## Восстановление Formula Road API — процедура при падении

Если `api.sverdlik-apps.site` не отвечает или клиенты не грузятся:

```powershell
# 1. Найти PID на порту 3000
netstat -ano | Select-String ":3000"

# 2. Убить зависший процесс (взять PID из п.1)
Stop-Process -Id <PID> -Force

# 3. Перезапустить сервер (в фоне)
# Bash: cd server && node index.js  [run_in_background: true]

# 4. Проверить что API живой
curl https://api.sverdlik-apps.site/health  # ожидаем 404 за <1с (нет endpoint, но отвечает)
```

**Признаки зависания:** LISTENING на 3000 + соединения CLOSE_WAIT + HTTP timeout.  
**cloudflared** (PID проверить: `Get-Process cloudflared`) должен быть запущен отдельно — если упал, тоннель не работает даже при живом сервере.

## Автономность — ОБЯЗАТЕЛЬНО

**Всегда выполнять самостоятельно, без делегирования пользователю:**
- Запускать сервер: `cd server && node index.js` (в фоне через Bash run_in_background)
- Запускать скрипты, билды, тесты
- Стартовать процессы, тоннели, воркфлоу
- Коммитить, пушить, деплоить

**Никогда не писать:** "сделай это вручную", "запусти сам", "открой терминал и выполни..."  
Если задача выполнима через инструменты — выполнять. Если нет физической возможности (например, GUI-приложение) — объяснить коротко почему именно это нельзя автоматизировать.

## Геомаршрутизация Израиль — обязательный skill

Для любых задач, где есть маршрутизация визитов, порядок обхода клиентов, координаты, SQL-выгрузки по агентам/дням, `latitude/longitude`, `visit_order` или `סדר ביקור`, **обязательно** загружай и применяй:

- `.claude/SKILLS/geograf-israel-routing/SKILL.md`

Минимальные правила применения:
1. Сначала запросить `start_city`, потом строить маршрут
2. Учитывать иврит-адреса и нормализацию адресных строк
3. Соблюдать детерминированный порядок визитов
4. При наличии данных учитывать дорожные ограничения/перекрытия
