---

## 1. Проблема

Владелец BI + Apps бизнеса тратит часы на:
- Ручное составление коммерческих предложений
- Расчёт стоимости проектов "на глаз"
- Квалификацию лидов без структуры
- Забывает follow-up → теряет сделки

**Результат:** конверсия лид → клиент низкая, много времени уходит на административную работу вместо delivery.

---

## 2. Решение — Closer Agent

AI-агент, который ведёт лида от первого контакта до подписанного договора.

### Основные функции

| Функция | Описание |
|---------|----------|
| **Lead Qualification** | Анализирует лида по фреймворку BANT (Budget, Authority, Need, Timeline) |
| **Scope Builder** | Задаёт вопросы → формирует scope of work |
| **Pricing Calculator** | Рассчитывает стоимость по типу проекта + сложности + часам |
| **Proposal Generator** | Создаёт PDF-предложение с описанием, ценой, ROI для клиента |
| **Follow-up Sequencer** | Планирует и напоминает о follow-up через N дней |
| **Deal Tracker** | Отслеживает статус сделок: New → Qualified → Proposal Sent → Negotiation → Won/Lost |

## 4. Фреймворк квалификации лида — BANT+

```
B — Budget:    Есть ли бюджет? Какой диапазон?
A — Authority: Я говорю с ЛПР (CEO/CTO/CFO)?
N — Need:      Какая конкретная боль? Что сейчас не работает?
T — Timeline:  Когда нужно? Есть дедлайн?
+ — Fit:       Power BI / App решит эту боль?
```

**Скоринг:** каждый пункт 0–2 балла.
- 8–10: горячий лид → предложение в течение 24ч
- 5–7: тёплый → уточнить детали → предложение через неделю  
- 0–4: холодный → nurture sequence / отказ

---

## 5. Структура коммерческого предложения

```
1. Executive Summary (1 абзац — боль клиента + наше решение)
2. Понимание задачи (что мы услышали)
3. Proposed Solution (что именно делаем)
4. Deliverables (список с описанием)
5. Timeline (план по неделям/этапам)
6. Investment (цена, опции)
7. ROI для клиента (сколько сэкономит/заработает)
8. Why Us (кейсы, технологии)
9. Next Steps (CTA — подписать, созвониться)
```

## 6. Follow-up последовательность

| День | Действие |
|------|----------|
| 0 | Отправлен proposal |
| 2 | Follow-up email: "Получили? Вопросы?" |
| 5 | Follow-up: "Можем созвониться на 15 мин?" |
| 10 | Последний follow-up: "Если сейчас не время — когда вернуться?" |
| 14 | Пометить как Cold / Lost → nurture |

## 9. MVP — что делает агент в первой версии

1. Задаёт BANT+ вопросы → скоринг лида
2. На основе ответов → выбирает тип проекта + рассчитывает цену
3. Генерирует текст proposal (Markdown/Word)
4. Даёт план follow-up с датами

**НЕ в MVP:** PDF, CRM интеграция, авто-отправка email.
