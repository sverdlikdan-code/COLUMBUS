## 🔴 Главная проблема — Star Schema нарушена

Вместо одной таблицы фактов с измерением "компания" — 4 одинаковые таблицы на каждую компанию:

### Текущая структура (40 таблиц — избыточно)
```
FORMULA DOCS ALL    \
ICE DOCS ALL         → должна быть 1 таблица DOCS ALL + столбец חברה
INTER DOCS ALL      /
MMD DOCS 24-NOW    /

FORMULA INV 24-NOW   \
ICE INV 24-NOW        → должна быть 1 таблица INV + столбец חברה
INTER INV 24-NOW     /
MMD INV 24-NOW       /

LAKOHOT SQL FORM     \
LAKOHOT SQL ICE       → должна быть 1 таблица LAKOHOT + столбец חברה
LAKOHOT SQL INTER    /
LAKOHOT SQL MMD      /
```

### Последствия текущей архитектуры
- Каждая мера дублировалась x4 → отсюда 252 меры (60% orphan)
- Медленные запросы в Fabric
- Новый поставщик/компания = ещё 4 таблицы + 50+ мер вручную
