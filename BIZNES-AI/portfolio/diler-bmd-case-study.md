# Кейс-стади: DILER BMD — BI + Apps для дистрибьютора еды

---

## Клиент
**DILER BMD** — дистрибьютор продуктов питания, Израиль. Агенты по полю, холодный склад, импортный и локальный ассортимент.

**Проблема до нас:** Маршруты в голове и WhatsApp. Менеджер не знал где агент. Склад на бумаге. Новые продукты терялись.

---

## Проект 1 — Formula Road

PWA-приложение для агентов и менеджеров. Без App Store, работает на любом телефоне.

- Агент открывает телефон → оптимизированный маршрут по Azure Maps
- GPS-коррекция в реальном времени
- Менеджер видит агентов на карте + KPI выполнения плана в Power BI

**Стек:** Node.js API, HTML/JS PWA, Azure Maps, Power BI Fabric, Cloudflare Tunnel

---

## Проект 2 — MAHSAN Planogram Editor

Интерактивная визуальная карта холодного склада. 4 секции (заморозка, молочка, рыба, сухая рыба).

- Каждая ячейка = реальный остаток из Power BI в реальном времени
- 🔴 Нулевой сток — автоматический индикатор
- ⭐ Новинка — бейдж с фото сразу после добавления в базу
- GitHub Actions CI/CD — данные обновляются каждую ночь без ручного труда

**Стек:** HTML/JS, Power BI Fabric + DAX, GitHub Actions

## Результаты

| Было | Стало |
|------|-------|
| Маршруты в голове / WhatsApp | Оптимизированный маршрут на телефоне каждое утро |
| Менеджер звонит агентам | Power BI дашборд в реальном времени |
| Остатки на бумаге | Живая планограмма с цветовой индикацией |
| Новинка — кто-то должен помнить | Автоматический бейдж с фото |

**Метрики:**
- Время планирования маршрута: 20–30 мин → 0
- Обнаружение нулевого стока: ручной обход → автоматически
- Внедрение новинки: несколько дней → мгновенно
- Деплой от нуля до продукта: ~6–8 недель
