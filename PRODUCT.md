# PRODUCT.md — Formula Road

## Product Purpose
Internal field-sales routing tool for FORMULA (Israeli food distribution company). Sales agents use it daily to plan client visit routes, track monthly sales vs targets, and manage GPS coordinates for clients.

## Users
Field sales managers (6) and their agents (33). Hebrew-speaking. Mobile-first — used on phones and tablets in the field. Some use on desktop for planning.

## Register
product

## Brand
- Primary: deep blue #1565C0 (DILER B.M.D brand color)
- Accent: gold #C9A84C (route markers)
- Success: green #1D6F42 (Excel-style)
- Warning: orange #FF8C00
- Error: red #b71c1c
- Dark background header: linear-gradient #1565C0 → #0D47A1

## Anti-references
- No SaaS cream / white + teal enterprise dashboards
- No neon / dark mode aesthetic
- No gradient text
- No identical card grids

## Tone
Professional, fast, no-nonsense. Hebrew RTL UI. Numbers and data are primary. No decorative copy.

## Key surfaces
1. Header — logo, agent name, last-updated timestamp
2. Agent/day selector pills
3. KM bar — distance savings badge
4. City filter chips
5. Sort buttons (visit order / AI / recalc / reset / XL save)
6. Client card list — RTL, visit number, name, city, address, last order, monthly sales, % target
7. Map — Leaflet, route polyline, numbered markers, popups with client info + fix location button
