1 Обзор проекта

Что это

MMD ORDERS — веб-приложение для управления заказами продуктов на склад MMD в Эйлате. Система позволяет менеджеру склада видеть актуальные остатки (MMD + Ашдод + транзитный склад), анализировать скорость продаж, получать рекомендацию к заказу и формировать заказ поставщикам в один клик.

Данные поступают в реальном времени из Power BI Fabric — никакого ручного ввода остатков. Система живёт по адресу, открытому через Cloudflare Tunnel поверх локального Node.js-сервера.

Пользователи

Приложение предназначено для одного пользователя — менеджера / кладовщика склада MMD (Эйлат). Аутентификация намеренно отсутствует — доступ ограничен на уровне Cloudflare Tunnel и сети.

ⓘ
Контекст: MMD ORDERS — один из модулей более широкой платформы COLUMBUS. Основной API-сервер (server/index.js) обслуживает несколько подсистем одновременно: Formula Road (маршруты агентов), MMD Orders (склад), планограмму Махсан и другие. MMD ORDERS подключается к отдельному Power BI датасету (POWERBI_MMD_DATASET_ID).

Маршрут данных
  1. Браузер открывает /mmd/ — сервер отдаёт index.html из папки MMD ORDERS/
  2. JS делает GET /pbi/mmd-orders?y1=&m1=&y2=&m2=
  3. Express обращается к Power BI REST API через MSAL (Client Credentials)
  4. Power BI выполняет DAX-запрос к таблицам Priority ERP
  5. Данные возвращаются как JSON, рендерятся в таблицу
  6. Заказ сохраняется в localStorage (ключ mmd-orders-v1)

4 Что реализовано

  • 🖐
    Splash-страница Люксовый тёмный экран загрузки с логотипом DILER, названием города Эйлат и датой последнего обновления Power BI. Исчезает с анимацией при нажатии "כניסה למערכת".
  • 📊
    Загрузка данных из Power BI в реальном времени DAX-запрос к таблицам KARTIS PARIT, тоקף FORM и DIMCALENDAR. Данные остатков (MMD, Ашдод, транзит), скорость продаж, рекомендация к заказу, срок годности — всё из PBI.
  • 📅
    Фильтр периода (timeline bar) Горизонтальная полоса с чипами месяцев: 14 месяцев назад + текущий. Поддержка выбора диапазона (клик начало, клик конец). Кнопка "ברירת מחדל" — предыдущий + текущий месяц.
  • 🔍
    Фильтр по семейству товара (multi-select) Выпадающий список с чекбоксами семейств. "Скрыть" / "Показать все". Счётчик скрытых семейств на кнопке.
  • 🏢
    Фильтр по компании Чипы компаний (חברה) генерируются динамически из данных. Одиночный или множественный выбор. Показывает счётчик заказанных единиц рядом с названием.
  • 📦
    Фильтр по наличию (Ашдод / MMD) Быстрые чипы: "יש 📦" / "חסר 😢" для каждого склада независимо. Default: показывать только товары с наличием в Ашдоде.
  • 📌
    Режим "только заказ" (📋 הזמנה בלבד) Переключатель, скрывающий строки без заказанного количества. Позволяет видеть только сформированный заказ.
  • 📈
    Группировка по семейству с subtotal Строки сгруппированы по mishpacha (תאור משפחה). Группы с заказами сортируются выше. Внутри группы — строки с заказами сначала.
  • 📝
    Редактируемое количество заказа Поле ввода (число) в каждой строке. По умолчанию заполняется рекомендацией PBI (המלצה). Изменения сохраняются в localStorage мгновенно (oninput).
  • 🕒
    Выбор тוקף (срок годности) заказа Select-список дат из поля тוקף PBI. Подсвечивается красным если дней мало (<14). Значение сохраняется в localStorage.
  • 📷
    Изображения товаров URL фото берётся из поля PBI (KARTIS PARIT[URL תמונה]). Ленивая загрузка. Fallback на серый прямоугольник при ошибке.
  • ⚠
    Подсветка критических остатков Строки с <10 днями до истечения срока — класс danger (красный). Ячейки с нулевым остатком — red. Более 3 недель запаса — green.
  • ⇩
    Экспорт Excel (ExcelJS, клиент) Скачивает только строки с ненулевым заказом. Форматированный xlsx: заголовок, дата, автофильтр, freeze строк, цветные ячейки заказа. Имя файла: MMD-Order-DD-MM-YYYY.xlsx.
  • 💾
    Сохранение и история заказов Кнопка "שמור" фиксирует снимок заказа в localStorage (до 30 записей). История открывается в popup с возможностью восстановить любой прошлый заказ.
  • 📷
    Печать Кнопка "הדפסה" вызывает window.print(). CSS @media print скрывает шапку / фильтры, показывает print-заголовок с датой, обеспечивает читаемую таблицу на бумаге.
  • 🔌
    PBI badge — время обновления датасета После загрузки показывает "⬆ עדכון PBI: DD/MM/YY HH:MM" в шапке и на splash-экране. Данные от getDatasetRefreshTime().
  • 🔐
    Rate limiting (серверный) 60 запросов/мин на IP для data endpoints (/pbi/mmd-orders, /pbi/dagim-sales). Защита от случайных циклов или DDoS.
  • 🛡
    Security headers X-Frame-Options: DENY, X-Content-Type-Options: nosniff, Referrer-Policy, X-XSS-Protection, Permissions-Policy — для всех ответов сервера.

6 Деплой и запуск

Запуск сервера
# Из корня проекта COLUMBUS
cd server
node index.js

# Или через PowerShell (фон)
# Bash run_in_background: true
cd server && node index.js

# Сервер слушает на порту:
PORT=3000 (из .env или default)
Проверка работоспособности
# Локальный тест
curl http://localhost:3000/pbi/mmd-orders

# Через туннель
curl https://api.sverdlik-apps.site/pbi/mmd-orders

# Открыть приложение
# https://api.sverdlik-apps.site/mmd/
Восстановление при зависании

Признаки: порт 3000 LISTENING + CLOSE_WAIT соединения + HTTP timeout.

# 1. Найти PID на порту 3000
netstat -ano | Select-String ":3000"

# 2. Убить процесс
Stop-Process -Id <PID> -Force

# 3. Перезапустить
cd server
node index.js

# Проверить cloudflared (туннель)
Get-Process cloudflared
# Если не запущен — туннель не работает!
Cloudflare Tunnel

Tunnel (cloudflared) — отдельный от Node.js процесс. Должен быть запущен независимо. Если туннель упал, а сервер работает — приложение всё равно недоступно извне.

Конфигурация туннеля хранится в Cloudflare Dashboard (не в репозитории).

✓
URL приложения: https://api.sverdlik-apps.site/mmd/ — прямой доступ к интерфейсу MMD Orders. API endpoint данных: https://api.sverdlik-apps.site/pbi/mmd-orders

7 Что осталось / TODO

  • High
    Мобильная адаптация
    Таблица имеет min-width: 1500px — не работает на телефоне. Нужна либо горизонтальная прокрутка с закреплённой первой колонкой, либо карточный вид для мобильных. Сервисные рабочие на складе могут использовать телефон.
  • High
    Автоматический перезапуск сервера (PM2 / Windows Service)
    Сейчас сервер не перезапускается после перезагрузки ПК или краша. Нужно добавить PM2 (pm2 start server/index.js --name columbus) или Windows Task Scheduler.
  • Medium
    Фото Эйлата на splash-экране
    Splash background сейчас тёмный градиент с геометрическим паттерном. Планировалось добавить реальное фото Красного моря / Эйлата (position: absolute; object-fit: cover; opacity: 0.12). В коде есть заготовка (#splash-overlay, #splash-sun — display:none).
  • Medium
    Push-уведомления / напоминания
    Уведомление менеджеру когда срок годности товаров критический (<10 дней). Возможная реализация: Service Worker + Web Push API + серверное расписание (cron).
  • Medium
    Отправка заказа по email / WhatsApp
    Сейчас единственный выход — скачать Excel и отправить вручную. Можно добавить POST /api/send-order с nodemailer или WhatsApp Business API для автоматической отправки поставщику.
  • Medium
    Кэширование PBI ответа
    Каждый нажатый "Refresh" делает полный DAX-запрос к PBI (~2-5 секунд). Добавить in-memory кэш с TTL 5-10 минут на стороне сервера. Ключ кэша: y1_m1_y2_m2.
  • Low
    Колонка "Компания" в Excel-экспорте — исправление BiDi
    Поле r.hevra (חברה) не проходит через fixBiDi() перед записью в Excel. На иврите может отображаться в зеркальном порядке в некоторых версиях Excel.
  • Low
    Темная тема для ночной смены
    Таблица сейчас светлая. Toggle prefers-color-scheme: dark или ручная кнопка. Шапка уже тёмная — нужно адаптировать фильтр-строку и таблицу.
  • Low
    Разделение history-ключа в localStorage
    Сохранение заказа (mmd-orders-v1) и история (mmd_order_history) используют разные форматы ключей. Стоит унифицировать под единый namespace mmd-orders.*.
