# Warehouse Floor Plan Generator

## Overview

Generates a live visual SVG floor plan from a parametric row/bay configuration.  
Tool: `warehouse-plan.html` — single file, open in any browser, no install required.

Location: `C:\Users\d.sverdlik\Desktop\WORKSPACE\PLANOGRAM MAHSAN FORMULA\warehouse-plan.html`

## When to Use

- User wants to visualize a warehouse room layout
- User changes bay counts per row and needs an updated schematic
- Planning a new room (Room 2, Room 3)
- Need to export a floor plan as SVG or PDF

## How to Use

1. Open `warehouse-plan.html` in any browser (double-click)
2. Edit the table:
   - **שורה** — row code (A, B, C …)
   - **תיאור** — row label
   - **Bay-ים** — number of bays in that row (type → redraws instantly)
   - **צבע** — color picker for the row
   - **קרוב לדוק** — check for the row nearest the dock
3. Add/remove rows with the buttons
4. Change room name, code, bay width, row height at the top
5. Export: **🖨️ Print → Save as PDF** or **⬇️ Export SVG**

## Modifying the Tool

All configuration is in the `rows` array at the top of the `<script>` block:

```js
let rows = [
  { id:1, name:'E', label:'שורה E', bays:10, color:'#D6E4F0', dock:true  },
  { id:2, name:'D', label:'שורה D', bays:12, color:'#E2EFDA', dock:false },
  // ...
];
```

Change defaults here to pre-load a different room configuration.

## Output

- **SVG** — vector, scalable, can paste into Word/PowerPoint/Visio
- **PDF** — browser print dialog → Save as PDF
- Each bay cell shows location code: `K-E01`, `K-E02` etc.

## Connecting to Planogram

The location codes in the floor plan (`K-E01-L1`, `K-E01-L2`) match exactly the location codes generated by `planogram-gen.js`. Same `roomCode` + row + bay format.
