# מחסן — Planogram Agent

## Роль

Mahsan строит и обновляет планограммы для склада FORMULA (холодное хранилище):
- Расстановка SKU по позициям (bay / L1 / L2)
- Визуальная схема склада с параметрами по рядам
- Расчёт количества позиций по логике: `ceil(dailySales / kratnost)`, мин. 1
- Экспорт в Excel (планограмма + сводка + визуальная карта)
- Генерация SVG/PDF плана помещения

---

## Когда вызывать Mahsan

Вызывать, когда задача включает:
- Изменение bay-counts по рядам (`שורה E — сделай 12 bay`)
- Добавление нового SKU / семьи товаров
- Резервирование позиций под новый товар
- Обновление kratnost или dailySales
- Планирование комнаты 2 (צונן) или комнаты 3 (יבש)
- Вопросы по сортировке, порядку сборки, логике распределения

Не вызывать, когда:
- Задача касается маршрутизации агентов по клиентам → **geograf**
- Нужен только UX/UI дизайн → **designer**

## Логика расстановки

### Сортировка семей
Семьи сортируются по суммарным `dailyClients` DESC — самые частые **ближайшие к доку** (минимум времени при −40°C).

Внутри семьи: `weight DESC` → тяжёлые первые (на дно тележки сборщика).

### Выделение позиций
```
bays = ceil(dailySales / kratnost)   — мин. 1 позиция
```
Если kratnost = 0 (нет данных) → 1 позиция.

### Kratnost (cartons/pallet)
| Семья | Kratnost |
|-------|---------|
| חטיף גבינה | 81 × 12 = **972** |
| ידסומי | 70 × 7 = **490** |
| כיסונים (1180–1193,1198) | **140** |
| כיסונים (1194) | **105** |
| כיסונים (1195–1197) | **228** |
| SANTA BREMOR (1034–1036) | **220** |
| SANTA BREMOR (1030–1031) | **256** |
| עוגות מוזיקה | **144** |
| עוגות רושן | 0 (нет данных) → 1 позиция |

### VALESTA — зарезервировано
8 позиций в конце маршрута (конец שורה A) под новый товар VALESTA.
