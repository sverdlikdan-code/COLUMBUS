**Методология (2026-08-23):** TMDL-экспорт живой модели через TE2 (read-only, XMLA) → парсинг всех 254 `measure` блоков → граф "мера ссылается на меру" (regex по `[Имя]` в DAX) + вычитка использования в живом отчёте (рекурсивный обход всех visual.json на предмет `Measure.Property`). "Неиспользуется" = не встречается ни в одном visual, ни в DAX другой меры. **Ограничение:** это прямые ссылки, не транзитические — если мера A используется только мерой B, а B сама нигде не используется, A всё равно посчитается "используемой". Не ловит использование через Analyze in Excel / внешние pivot-подключения (не часть этого отчёта).
